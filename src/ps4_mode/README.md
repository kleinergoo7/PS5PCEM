# PS4 Mode (experimental, scaffold)

This directory is a placeholder scaffold for an experimental PS4 compatibility mode
analogous to SharpEmu's GNM mode. It is intentionally minimal; refinement is
expected by downstream work.

Planned components:
- ELF/SELF loader + param SFO parsing
- PS4 HLE service shims
- GCN/GNM -> RDNA2 translation frontend
- Launch/detection integration
